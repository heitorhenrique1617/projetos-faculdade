# Currículo Web — Vitor Fernando

Projeto desenvolvido com HTML5 e Bootstrap 5 com o objetivo de criar uma página web pessoal apresentando um currículo profissional responsivo.

---

## Objetivo do Projeto

Desenvolver uma página web pessoal que apresente:
- informações profissionais;
- formação acadêmica;
- habilidades;
- experiências;
- contato profissional.

O projeto foi construído utilizando HTML e Bootstrap, aplicando conceitos de responsividade, estruturação semântica e estilização moderna.

---

## Tecnologias Utilizadas

- HTML5
- Bootstrap 5
- CSS utilitário do Bootstrap
- JavaScript Bundle Bootstrap

---

## Funcionalidades

- Navbar responsiva
- Menu mobile com botão hamburguer
- Foto de perfil
- Sessões organizadas
- Layout responsivo para dispositivos móveis
- Rodapé estilizado
- Uso de componentes utilitários do Bootstrap

---

## Estrutura da Página

A página possui:

- Home
- Sobre
- Projetos
- Contato
- Quem sou eu
- Objetivo profissional
- Formação acadêmica
- Experiência profissional
- Habilidades

---

## Conceitos Aplicados

Durante o desenvolvimento foram utilizados conceitos como:

- Containers responsivos
- Margin e Padding (`mt`, `mb`, `p`)
- Font Size (`fs`)
- Responsividade com Bootstrap
- Navbar responsiva
- Grid system
- Classes utilitárias
- Imagens responsivas
- Estilização com `bg-dark`, `text-white`, `rounded`, entre outros
